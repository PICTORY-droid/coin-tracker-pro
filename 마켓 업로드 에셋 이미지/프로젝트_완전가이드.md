## 1️⃣ 프로젝트 개요

### 📌 이 앱이 뭔가요?

> 코인(가상화폐) 투자자들이 업비트·빗썸 거래소의 실시간 시세를 구글 시트에서 자동으로 확인하고 수익률을 자동 계산할 수 있는 도구입니다.

### ✅ 주요 기능

| 기능 | 설명 |
|---|---|
| 실시간 시세 자동 반영 | 업비트·빗썸 API 연동, 1분마다 자동 갱신 |
| 수익률 자동 계산 | 평가금·수익금·수익률 자동 계산 |
| 목표가·손절가 이메일 알림 | 도달 시 이메일 즉시 발송 |
| 매수·매도 히스토리 자동 기록 | 거래 자동 저장, 평균단가 자동 반영 |
| 업비트·빗썸 동시 연동 | 두 거래소 통합 관리 |
| KRW·USD 동시 표시 | 환율 자동 반영 |
| 수익 실현 시뮬레이터 | 매도 전 예상 수익 즉시 계산 |
| 주간·월간 요약 이메일 | 포트폴리오 자동 발송 |

## 3️⃣ Google Apps Script 코드 작성

### 📌 파일 구조

```
실시간 코인 트래커 Pro/
├── Code.gs          ← 메인 코드 (전체 기능)
├── appsscript.json  ← 프로젝트 설정
└── README.md        ← 사용 가이드
```

### 📌 Code.gs 설명

> Code.gs 파일은 앱의 모든 기능이 담긴 핵심 파일이에요.
> Google Apps Script는 JavaScript 기반으로 작성합니다.

**주요 함수 목록**

| 함수명 | 역할 |
|---|---|
| onOpen() | 구글 시트 열릴 때 메뉴 자동 생성 |
| initializeSheets() | 4개 시트 자동 생성 |
| updatePrices() | 업비트·빗썸 시세 업데이트 |
| fetchUpbitPrices() | 업비트 API 호출 |
| fetchBithumbPrices() | 빗썸 API 호출 |
| getUSDRate() | 환율 조회 |
| openBuyDialog() | 매수 입력 팝업 |
| openSellDialog() | 매도 입력 팝업 |
| recordTrade() | 거래내역 자동 기록 |
| checkAlerts() | 목표가·손절가 체크 후 이메일 발송 |
| openSimulator() | 수익 시뮬레이터 팝업 |
| setupTrigger() | 1분 자동 업데이트 트리거 설정 |
| sendWeeklySummary() | 주간 요약 이메일 발송 |
| sendMonthlySummary() | 월간 요약 이메일 발송 |

### 📌 업비트 API 연동 방법

> 업비트는 누구나 무료로 사용할 수 있는 공개 API를 제공해요.
> 별도 API 키 없이 바로 사용 가능합니다!

```javascript
// 업비트 API 호출 예시
const url = 'https://api.upbit.com/v1/ticker?markets=KRW-BTC';
const response = UrlFetchApp.fetch(url);
const data = JSON.parse(response.getContentText());
const currentPrice = data[0].trade_price; // 현재가
```

### 📌 빗썸 API 연동 방법

```javascript
// 빗썸 API 호출 예시
const url = 'https://api.bithumb.com/public/ticker/BTC_KRW';
const response = UrlFetchApp.fetch(url);
const data = JSON.parse(response.getContentText());
const currentPrice = data.data.closing_price; // 현재가
```

### 📌 시트 구조

**📊 포트폴리오 시트**
```
A열: 거래소 (업비트/빗썸)
B열: 코인명 (비트코인 등)
C열: 심볼 (BTC, ETH 등)
D열: 현재가 KRW ← 자동
E열: 전일대비 % ← 자동
F열: 현재가 USD ← 자동
G��: 보유수량 ← 직접 입력
H열: 매수평균가 ← 직접 입력
I열: 평가금 ← 자동
J열: 수익금 ← 자동
K열: 수익률 ← 자동
L열: 메모 ← 직접 입력
```

**📋 거래내역 시트**
```
A열: 날짜·시간 ← 자동
B열: 거래소 ← 자동
C열: 코인명 ← 자동
D열: 심볼 ← 자동
E열: 구분 (매수/매도) ← 자동
F열: 수량 ← 자동
G��: 거래가격 ← 자동
H열: 거래금액 ← 자동
I열: 수수료 ← 자동
J열: 비고 ← 자동
```

**⚙️ 알림설정 시트**
```
B2: 알림 받을 이메일 주소
B3: 주간 요약 ON/OFF
B4: 월간 요약 ON/OFF
6행: 헤더 (거래소/코인명/심볼/목표가/손절가/알림)
7행~: 코인별 알림 설정
```

## 4️⃣ 구글 시트 설치 및 실행

### 📌 STEP 1 — 구글 시트 새 파일 만들기

```
1. 브라우저에서 sheets.google.com 접속
2. 구글 계정으로 로그인
3. 왼쪽 상단 [+ 새 스프레드시트] 클릭
4. 빈 구글 시트가 열립니다
5. 상단 파일명 클릭 → 이름 변경
   → "실시간 코인 트래커 Pro — 업비트"
```

### 📌 STEP 2 — Apps Script 열기

```
1. 구글 시트 상단 메뉴
2. [확장 프로그램] 클릭
3. [Apps Script] 클릭
4. 새 탭에 Apps Script 편집기가 열립니다
```

### 📌 STEP 3 — 코드 붙여넣기

```
1. 편집기 왼쪽에 [Code.gs] 파일 확인
2. 편집기 안의 기존 코드 전체 선택 (Ctrl+A)
3. Delete 키로 전부 삭제
4. Code.gs 파일 내용 전체 복사
5. 편집기에 붙여넣기 (Ctrl+V)
6. 저장 (Ctrl+S)
7. 프로젝트 이름을 "실시간 코인 트래커 Pro"로 변경

### 📌 STEP 4 — 첫 실행 및 권한 허용

```
1. 상단에서 함수 선택: onOpen 선택
2. ▶ 실행 버튼 클릭
3. 권한 요청 팝업 등장!

팝업 처리 방법:
   → [권한 검토] 클릭
   → 본인 구글 계정 선택

   → [실시간 코인 트래커 Pro (안전하지 않음)으로 이동] 클릭
   → 아래로 스크롤 → [허용] 클릭

4. 구글 시트 탭으로 돌아오기
5. F5 새로고침
6. 상단 메뉴에 [🚀 실시간 코인 트래커 Pro] 등장!
```

### 📌 STEP 5 — 시트 초기 설정

```
1. 상단 [🚀 실시간 코인 트래커 Pro] 클릭
2. [🔧 시트 초기 설정] 클릭
3. 잠시 기다리면 4개 시트 자동 생성!
   → 📊 포트폴리오
   → 📋 거래내역
   → ⚙️ 알림설정
   → 📈 대시보드
4. "초기 설정 완료!" 팝업 → [확인] 클릭
```

### 📌 STEP 6 — 코인 정보 입력

```
1. 하단 [📊 포트폴리오] 탭 클릭
2. 노란색 칸에만 입력!

입력 예시:
A열 거래소    : 업비트
B열 코인명    : 비트코인
C열 심볼      : BTC  ← 반드시 영문 대문자!
G�� 보유수량  : 0.5  ← 내가 가진 수량
H열 매수평균가: 98500000  ← 콤마 없이 숫자만!
L열 메모      : 장기 보유 (선택사항)

주의사항:
→ D·E·F·I·J·K열은 자동 계산 (수정 금지!)
→ 심볼은 반드시 영문 대문자 (BTC, ETH, XRP)
→ 매수평균가는 콤마 없이 숫자만 (98500000)
```

### 📌 STEP 7 — 이메일 알림 설정

```
1. 하단 [⚙️ 알림설정] 탭 클릭
2. B2칸 클릭 → 이메일 주소 입력
   예: investor@gmail.com
3. B3칸: ON (주간 요약 받기)
4. B4칸: ON (월간 요약 받기)

코인별 알림 설정 (7행부터):
A열: 업비트 또는 빗썸
B열: 코인명 (비트코인)
C열: 심볼 (BTC)
D열: 목표가 (130000000) ← 1억 3천만원
E열: 손절가 (85000000)  ← 8천5백만원
F열: ON 또는 OFF

주의: 목표가·손절가는 콤마 없이 숫자만!
```

## 6️⃣ 구글 클라우드 프로젝트 설정

### 📌 구글 클라우드란?

> 구글이 제공하는 서버·서비스 플랫폼이에요.
> 마켓플레이스에 앱을 등록하려면 구글 클라우드 프로젝트가 필요해요.

### 📌 중요! 계정 통일

```
아래 3가지 모두 같은 구글 계정으로 해야 해요!

1. 구글 시트 (코인 트래커 만든 계정)
2. script.google.com (Apps Script)
3. console.cloud.google.com (구글 클라우드)

다른 계정으로 하면 연결이 안 돼요!
```

### 📌 STEP 1 — 구글 클라우드 접속

```
1. https://console.cloud.google.com 접속
2. 구글 계정으로 로그인
   (구글 시트와 같은 계정!)
3. 서비스 약관 동의

## 💡 자주 묻는 질문 (FAQ)

**Q. 메뉴가 안 보여요**
```
A. Apps Script에서 onOpen 함수를 실행한 후
   구글 시트에서 F5 새로고침 하세요!
```

**Q. 시세가 업데이트 안 돼요**
```
A. 메뉴 → API 연결 테스트 클릭
   오류가 있으면 자동 업데이트를 중지했다가
   다시 시작해보세요.
```

**Q. 이메일 알림이 안 와요**
```
A. 알림설정 시트에서
   1. 이메일 주소가 올바른지 확인
   2. 알림 칸이 ON인지 확인
   3. 목표가·손절가가 현재가 기준으로 맞게 설정됐는지 확인
```

**Q. 깃허브에 다른 파일들이 같이 올라갔어요**
```
A. 상위 폴더에 git이 설정된 경우예요.
   git remote remove origin 후
   git remote add origin [새 저장소 주소]
   git push -u origin main 으로 해결하세요.
```

**Q. 구글 클라우드 연결이 안 돼요**
```
A. Apps Script 계정과 구글 클라우드 계정이
   같은 계정인지 확인하세요!
   다른 계정이면 연결이 안 돼요.
```
