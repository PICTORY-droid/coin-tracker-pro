\# 실시간 코인 트래커 Pro



업비트·빗썸 실시간 시세 자동 반영, 수익률 즉시 계산, 목표가 이메일 알림까지.

코인 투자자를 위한 올인원 포트폴리오 관리 Google Sheets 애드온.



\## 주요 기능

\- 실시간 시세: 업비트·빗썸 API 연동, 1분마다 자동 갱신

\- 수익률 계산: 평가금·수익금·수익률 자동 계산

\- 거래 히스토리: 매수·매도 자동 기록, 평균단가 자동 반영

\- 이메일 알림: 목표가·손절가 도달 시 즉시 이메일 발송

\- 빗썸 연동: 업비트·빗썸 동시 포트폴리오 관리

\- 코인별 메모: 투자 이유·전략 메모 기록

\- 현금 비율: 총 투자금 대비 현금 비율 자동 표시

\- 수익 시뮬레이터: 특정 수량 매도 시 예상 수익 즉시 계산

\- 주간·월간 이메일: 포트폴리오 요약 자동 발송

\- KRW·USD 동시 표시: 환율 자동 반영



\## 시작하는 방법

1\. Google Sheets 열기

2\. 확장 프로그램 → Apps Script

3\. Code.gs 내용 전체 붙여넣기

4\. 저장 후 시트로 돌아가기

5\. 메뉴 → 실시간 코인 트래커 Pro → 시트 초기 설정

6\. 포트폴리오 시트 노란칸에 코인 정보 입력

7\. 메뉴 → 자동 업데이트 시작



\## 시트 구조

\- 포트폴리오: 메인 시세·수익률

\- 거래내역: 매수·매도 히스토리 자동 기록

\- 알림설정: 목표가·손절가·이메일 설정

\- 대시보드: 종합 현황·거래소별 분리·시뮬레이터



\## UX 규칙
